# План презентации (≤ 15 минут)

1. **Титул / вводная** (1 мин) — тема: анализ продаж видеоигр по платформам; автор: Черноусов; цель: понять, какие платформы лидируют; мотивация: данные индустрии, наглядный дашборд.
2. **Образ результата** (1,5 мин) — проблема: 16 тыс. строк, сложно увидеть тренды; задача: фильтровать по годам и сравнивать платформы; результат: веб-дашборд с графиком и таблицей.
3. **Архитектура** (2 мин) — схема вход → обработка → выход; модули (`app`, `analysis`, `charts`, `data_loader`); технологии: Flask, pandas, matplotlib; данные: CSV (Kaggle vgsales).
4. **Логика и демонстрация** (5 мин) — разбор `filter_by_year_range`, `platform_total_sales` / `platform_average_sales`; почему отдельный модуль `analysis.py` (тестируемость, переиспользование из Colab); **живая демо**: сменить годы → метрику → Топ-N.
   Интересный вывод для демо: по средним продажам лидируют GB и NES (хиты Nintendo), а по суммарным — PS2, X360, PS3.
5. **Тестирование** (2 мин) — 15 тестов pytest: unit-тесты логики + тесты Flask; обработка некорректного ввода; запуск `python -m pytest -v`.
6. **Контроль версий и документация** (1 мин) — показать GitHub, README (запуск, функциональность), историю коммитов.
7. **Заключение** (1,5 мин) — что получилось: Colab-ноутбук → полноценное веб-приложение; что можно улучшить: SQLite, API, ML-прогноз продаж; указать использование ИИ (DeepSeek, Claude).
