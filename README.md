# Анализ продаж видеоигр по платформам

Веб-приложение на Flask: интерактивный дашборд по датасету
[vgsales](https://www.kaggle.com/datasets/kedokedokedo/vgsales) (16 324 игры, 1980–2016).

## Цель и функциональность
Показать, какие игровые платформы лидируют по продажам. В интерфейсе можно:
- выбрать диапазон лет;
- выбрать метрику: **суммарные продажи** или **средние продажи на игру**;
- выбрать размер рейтинга (Топ-5 … Топ-20);
- получить график, таблицу рейтинга и сводку (число игр, платформ, объём продаж).

## Архитектура: вход → обработка → выход
| Этап | Что происходит | Файл |
|---|---|---|
| Вход | параметры формы (годы, метрика, N) + CSV | `app.py`, `data_loader.py` |
| Обработка | очистка, фильтрация по годам, группировка | `analysis.py` |
| Выход | график (PNG, base64) + HTML-страница | `charts.py`, `templates/index.html` |

## Запуск в PyCharm
1. `File → Open` → выберите папку проекта.
2. Создайте виртуальное окружение (PyCharm предложит сам) и в терминале выполните:
   ```
   pip install -r requirements.txt
   ```
3. Запустите `app.py` (правая кнопка → Run) и откройте http://127.0.0.1:5000
4. При первом запуске датасет скачается с Kaggle в `data/vgsales.csv`.
   Если скачивание не удалось — скачайте `vgsales.csv` вручную и положите в `data/`.

## Тестирование
```
python -m pytest -v
```
- `tests/test_analysis.py` — 10 unit-тестов функций анализа на маленьком датафрейме с известными ответами;
- `tests/test_app.py` — 5 тестов интерфейса (Flask test client): значения по умолчанию, обе метрики,
  пустой диапазон, некорректные параметры, перепутанные годы.

## Используемые технологии
Python, Flask, pandas, matplotlib, pytest, kagglehub. Формат данных: CSV.

## Запуск в Docker
```
docker compose up --build
```
Приложение будет доступно на http://localhost:8000. Остановить: `Ctrl+C`, затем `docker compose down`.
Датасет хранится в папке `data/` (подключена как volume), поэтому повторно не скачивается.
